## FEATURES

### Widget Collection
* **Photo Widget:** Custom photos to the home screen.
* **Drawing Widget:** A dynamic home screen notebook and canvas.
* **Auto-Playing Snake Widget:** The retro dot-matrix game that plays itself on the launcher.
* **Water Widget:** Interactive fluid physics right on the home screen.
* **Hourglass Widget:** A tilt-sensitive falling sand timer.
* **Maze Widget:** A fully playable, tilt-sensitive physics labyrinth.
* **Fidget Gear Widget:** Interactive rotating mechanical gears.
* **Coin Toss Widget:** A quick 50/50 decision maker.

### Game Collection
* **Snake Game:** The classic arcade survival game.
* **Flappy Bird:** The tap-to-fly physics challenge.
* **Tetris:** The block-stacking puzzle legend.
* **Breakout:** The paddle-and-ball brick breaker.
* **My Planet:** Save the planet from alien attacks.
* **Maze Ball:** Maze adventures with red ball

### Tool Collection
* **WhatsApp Sticker Maker:** Custom sticker generator with full WhatsApp integration.
* **PDF Studio:** A dedicated engine to manage and create PDFs.
* **Image Studio:** A comprehensive, all-in-one image editing suite featuring:
  * *Base Editor:* Complete with cropping, color adjustments, text overlays, grid alignments, and a smart Background Remover.
  * *Pro Canvas:* A professional drawing workspace with zero-lag pathing, flood fill, live color wheels, and an advanced brush arsenal.
  * *Clone Tool:* A desktop-class cloning engine featuring multi-touch rotation, Live Ghost Overlays, and perfect pixel-cloning.
  * *Background Remover:* Remove background Manually and use auto color for rermoving the selected color automatically.
* **Collage Studio:** An image editing tool dedicated for collage editing that supports upto 50 images collage.
* **Audio Studio:** A music editing tool dedicated for Audio editing that supports multilayer mixing

### Utility Collection
* **Private Browser:** Secure browser that respects your privacy, deletes all the data when user closes the browser.
* **DOC reader:** Utility for reading doc and word files.
* **Slate:** Utility for vibe drawing/rough notes.
* **Text Pad:** Utility for rough text notes.

## INSTALLATION

### For Regular Users
If you just want to install and use the app on your Android device:

1. Navigate to the [Releases](../../releases) section of this repository.
2. Download the latest `.apk` file.
3. Open the file on your phone (you may need to enable "Install Unknown Apps" in your settings).
4. *Note for Samsung users:* If the installation is blocked, temporarily disable "Auto Blocker" in your Security & Privacy settings.
